# Folder Structure

This document explains the folder structure of the portfolio website project.

## Root Directory
- `src/` – Main application source code
- `docs/` – Project documentation
- `scripts/` – Build and deployment scripts
- `assets/` – Static assets (images, fonts, etc.)

## src/
- `App.tsx` – Main application component
- `main.tsx` – Application entry point
- `index.css` – Global styles
- `types.ts` – TypeScript type definitions
- `data.ts` – Application data and configuration
- `imageAssets.ts` – Image asset management

### src/components/
- `Header.tsx` – Site navigation header
- `ProjectPreviews.tsx` – Project preview grid
- `DesignStoryCanvas.tsx` – Interactive design stories
- `CaseStudyDetail.tsx` – Detailed case study view
- `ContactForm.tsx` – Contact form component
- `PhotoReel.tsx` – Photo carousel component
- `TheatreCurtain.tsx` – Animation component

### src/assets/
- `images/` – All image assets organized by project
  - `project_preview_*.png` – Project preview images
  - `story_*.png` – Story images for each project
  - `profile_*.png` – Profile images

## docs/
- `architecture.md` – Architecture decisions and tech stack
- `components.md` – Component guidelines and documentation
- `folder-structure.md` – Detailed folder structure explanation

## scripts/
- (To be populated with build and deployment scripts)
